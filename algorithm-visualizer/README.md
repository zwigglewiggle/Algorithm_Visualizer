# Algorithm Visualizer

Ein interaktiver Algorithmus-Visualisierer in C++ mit Fokus auf sauberer Architektur, moderner Visualisierung und Portfolio-Tauglichkeit.

## Geplante Features
- Sortieralgorithmus-Visualisierung
- Playback mit Pause/Resume/Step
- moderne UI
- Metriken und Vergleichsansichten

## Tech-Stack
- C++20
- CMake
- SFML
- Dear ImGui
